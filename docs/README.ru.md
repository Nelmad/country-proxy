# Country Proxy — русское руководство

[English overview](../README.md) · [English getting started](getting-started.md) ·
[Помощь / Support](../.github/SUPPORT.md) · [Безопасность / Security](../.github/SECURITY.md)

[MIT License](../LICENSE) · [Сторонние зависимости](../NOTICE)

Расширение Chrome для бесплатных публичных прокси: выбираете страну, оно ищет
адрес, проверяет HTTPS и страну выхода, подключает и начинает замену при отказе.
Доступен каталог 249 стран и территорий с поиском по русскому, английскому
названию или ISO-коду. Наличие рабочего адреса проверяется после выбора страны.

Технический минимум — Chrome 120+, Python 3.11+ и локальный помощник. Полный
сценарий проверяется на macOS в отдельном Chrome for Testing; нижние версии
диапазона не проверены отдельно. [Состав первого stable и критерии готовности](stable-readiness.md).
Установщик также поддерживает Linux, но полный браузерный сценарий на Linux
пока не проверен. Windows и Incognito не поддерживаются. Аккаунты и ключи не нужны.

## Установка

Для обычной установки используйте комплект `country-proxy-X.Y.Z.zip` из
[GitHub Releases](https://github.com/Nelmad/country-proxy/releases), когда выпуск
опубликован. Текущее состояние версий — в [CHANGELOG](../CHANGELOG.md).
ZIP, собранный локально или скачанный из ветки, может содержать ещё не выпущенный код.

Для первого знакомства используйте отдельный профиль Chrome. Поиск и подключение
меняют маршрут всех вкладок этого профиля; пока подходящий адрес не найден,
HTTP/HTTPS заблокирован. Кнопка **Отключить** освобождает настройки Country Proxy.

1. Распакуйте комплект в **постоянную папку**: помощник запоминает её путь.
2. Запустите `Install.command` на Mac. Он установит зависимости в `.venv` этой
   папки и зарегистрирует Native Messaging helper. Для Linux — `python3 scripts/install.py`.
3. В `chrome://extensions` включите режим разработчика, выберите
   **Загрузить распакованное расширение** и папку `extension` из того же комплекта.
4. Закрепите Country Proxy, откройте выбор страны и нажмите нужную страну:
   поиск и подключение начнутся автоматически.

[Подробная установка, обновление и откат](installation.md).
Установка помощника и загрузка расширения — два обязательных шага. Отдельный
терминал или постоянно работающий системный сервис не нужны.

## Использование

Есть два режима: **Одна страна** и **Несколько стран**. Во втором отметьте нужные
страны и нажмите **Подключить выбранные**. Например, EE, NO и PL образуют один
равноправный набор: порядок галочек и страна текущего адреса не задают приоритет.
Редактирование набора и отмена не меняют соединение до применения.

- **Выбор страны:** откройте каталог и найдите название или код, например `JP`.
  В режиме одной страны нажатие сразу запускает подключение; ввод поискового запроса ничего
  не переключает. При первой установке страна не выбрана.
- **Избранное.** Звёздочка рядом со страной добавляет её в быстрый выбор. Список также доступен в настройках. Изменения в разных окнах объединяются; кнопка сохранения применяет только ваши добавления и удаления. Если одну страну изменили в обоих окнах, действует последнее сохранённое изменение.
- **Сохранённые группы.** До первого подключения откройте «Сохранённые группы» и нажмите «Создать группу». Назовите её и выберите страны. Когда страны уже выбраны, кнопка «Сохранить выбранные страны» подставляет их как начальный состав. Чтобы изменить состав или название существующей группы, нажмите «Изменить». Новые страны вступят в действие при явном подключении группы.
- **Перенос групп.** В настройках нажмите «Скачать группы». В другом профиле откройте «Загрузить из файла» и выберите сохранённый JSON. Расширение добавит новые группы и сообщит, сколько совпало по названию или составу. Файл содержит только названия групп и страны.
- **Найти другой:** запускает замену вручную.
- **Отключить:** освобождает настройки прокси Chrome.

Во время поиска и подключения откройте **Вклад источников** и выберите страну
списка. В таблице видно, сколько рабочих адресов дал каждый источник и сколько
из них подтвердил Chrome. Если один адрес нашли несколько поставщиков, они
делят один балл. Страна в таблице меняет только отчёт.

Повторяющиеся неисправные адреса временно пропускаются. После паузы помощник
проверяет их заново. История хранится локально у помощника и очищается автоматически.
Профили Chrome внутри одной папки данных могут использовать общую историю;
настройки стран каждого профиля остаются отдельными.
[Как работает карантин и как очистить историю](runbook.md#повторяющийся-отказ-и-очистка-истории).

Помощник предлагает первый адрес с рабочим HTTPS и допустимой страной выхода.
Соединение подтверждает Chrome. При отказе помощник проверяет до двух свежих
резервов одновременно. Если Chrome отклонит первый ответивший адрес, помощник
попробует оставшийся резерв. Когда резервы исчерпаны, поиск продолжается внутри
выбранного набора. В режиме одной страны набор состоит
из неё одной. Если адресов нет, поиск повторяется автоматически. Помощник начинает проверять адреса из готовых списков, пока другие источники
ещё отвечают. У каждой выбранной страны сохраняется своя очередь. Работающий адрес
сохраняется; периодической смены страны по таймеру нет. В popup отдельно показаны
разрешённый набор и фактическая страна выхода.

Статус **Подключено** появляется после проверки самим Chrome. Popup показывает
подтверждённый браузером выходной IP, время проверки, число резервов и причины отказов.
Пока идёт проверка в Chrome, IP подписан как результат проверки помощника.
Новые запросы вкладок в это время заблокированы; через кандидат идут только
служебные проверки расширения. После подтверждения обновите страницу, если
сайт сам не повторил запрос. Автоматической повторной отправки форм нет.
Резерв готовит помощник, а Chrome проверяет его при переключении. Если резерв
пуст, откройте **Диагностика резерва**. Там видны стадия пополнения и причины
пропуска адресов с начала текущего подключения для всей выбранной группы.

При поиске, проверке, смене страны и потере помощника новые обычные HTTP/HTTPS
запросы профиля Chrome блокируются, включая запросы уже открытых вкладок и
localhost. Разрешение `declarativeNetRequest` нужно для блокировки запросов;
расширение не получает доступ к содержимому всех сайтов. Если proxy-настройки
перехватила политика или другое расширение, появится ошибка и собственная
блокировка останется до **Отключить**. Уже отправленный трафик и ранее открытые
соединения нельзя отозвать задним числом. Чтобы освободить свои настройки,
нажмите **Отключить**.
Системный прокси не меняется; расширение не является VPN для всей ОС.

## Что проверяется и какие есть ограничения

Каждый адрес проходит два HTTPS-запроса с проверкой сертификатов и Cloudflare
GeoIP, затем проверку в браузере. Поддерживаются HTTP CONNECT, HTTPS-прокси,
SOCKS4 и SOCKS5. В фоне готовится до двух резервов всего набора с другими host/выходными IP.
Поиск повторяется автоматически, если подходящих адресов нет.

Бесплатные адреса нестабильны. Программа не гарантирует два живых прокси в
каждой стране или доступ к любому сайту. Успешный тест механизма замены на стенде
и успешная замена между двумя публичными IP фиксируются отдельно.
Публичными прокси управляют неизвестные третьи лица. Проверка HTTPS подтверждает
работающий маршрут к контрольным хостам с проверкой сертификатов, а не
добросовестность оператора, отсутствие логов или анонимность. Обычный HTTP до
сайта не шифруется. HTTPS сам по себе не делает публичный прокси подходящим для
чувствительных действий: используйте для них доверенное соединение. Для
знакомства и проверки публичных страниц используйте отдельный профиль без
личных аккаунтов. [Данные и разрешения (English)](getting-started.md#data-and-permissions).
