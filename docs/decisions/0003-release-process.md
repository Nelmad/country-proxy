# 0003 — Один поток разработки и отдельный выпуск

Дата: 2026-10-29. Статус: принято для локального процесса; удалённые настройки
репозитория и публикация этим решением не выполняются.

Country Proxy поставляет Chrome extension и Native Messaging helper совместно.
Нужны понятная связь кода с установленным комплектом и возможность отката; отдельная
develop-ветка и автоматическая публикация пока не дают пользы для одного владельца.

Используем короткие codex/* ветки, PR/review, main, неизменяемый опубликованный
тег vX.Y.Z и GitHub Release с ZIP/checksum/notes. Manifest — источник версии.
CI выполняет только offline checks. Exact commit и история проходят отдельную
проверку перед разрешённой публикацией. Сборщик выдаёт локальный inventory и
checksum, но не аттестует Git и не публикует.

Установка обновляется целиком в постоянной папке: регистрация helper содержит
абсолютные пути. Публикация Release не обновляет Chrome автоматически. Проверки
механизма и доступности публичных стран разделены; PARTIAL не превращается в PASS.

Следствия: меньше постоянных веток, один комплект extension/helper, явные
обновление/откат, неизменяемые опубликованные assets. Автопубликация, Web Store и
автообновление helper потребуют отдельного решения и проверок.

Каноническая процедура — [releases.md](../releases.md), пользовательская —
[installation.md](../installation.md).
