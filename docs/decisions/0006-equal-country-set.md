# ADR 0006 — Равноправный набор стран

Дата: 2026-10-30. Статус: принято для локальной реализации.
Дополняет [ADR 0005](0005-country-selection.md); одиночный режим сохраняется.

## Решение

Пользователь может выбрать несколько стран как один разрешённый набор. Они
равноправны: ни порядок выбора, ни страна текущего адреса не дают приоритета.

Набор отмечается галочками и применяется отдельной кнопкой. Черновик, поиск,
избранное и отмена не меняют соединение. Сохраняются mode и канонический набор;
фактическая страна активного выхода отображается отдельно. Старый одиночный
выбор мигрирует без расширения разрешённых стран. Неверный включённый набор
блокируется целиком до явного исправления.

Общий поиск перемешивает список стран независимо от порядка выбора и справедливо
чередует их кандидатов. Глобальные пределы: 120 кандидатов, 10 проверок одновременно,
2 резерва; получение источников — 3 страны одновременно и 45 секунд на проход.
Побеждает первый успешно проверенный адрес, затем требуется подтверждение Chrome.
При отказе берётся проверенный резерв с меньшей задержкой из всего набора, затем
выполняется общий поиск. Здоровое соединение не меняется по таймеру. При пустом
пуле повторяется тот же поиск без выхода за выбранный набор.

Это равноправие допустимых стран, а не обещание равной частоты подключений:
доступность, число кандидатов и время ответа отличаются. При большом наборе
ограниченный проход может не успеть опросить все страны; следующий проход
перемешивает их заново и UI получает предупреждение.

## Проверка и совместимость

Native и Chrome независимо проверяют принадлежность фактической страны набору.
События связаны с ID поколения и точным набором, чтобы поздний ответ не вернул
исключённую страну. Проверки охватывают переходы между странами, отсутствие приоритета,
ограничение нагрузки, отмену и несовместимые сохранённые настройки.

Браузерный стенд с настоящим HTTPS/GeoIP подтверждает UI, автоматическую замену,
сохранённый набор и отказ выхода вне набора. Его loopback-адреса имеют общий
внешний выход, поэтому этот PASS не означает живую межстрановую пару.

Старые комплекты не понимают новый режим. Перед откатом нужен явный одиночный
выбор и отключение; порядок — в [установке](../installation.md#откат).
