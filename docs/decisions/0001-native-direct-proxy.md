# 0001 — Поиск в Native Messaging, трафик Chrome напрямую к upstream

Статус: принято для локальной версии 0.1.0. Дата: 2026-10-27.

Пользователь выбирает настраиваемую страну, расширение самостоятельно ищет, проверяет и заменяет бесплатный прокси. В пробном запуске proxy-scraper RotatingServer не смог обслужить найденный норвежский адрес, хотя curl подключался за 19–23 секунды. Причина ошибки посредника не установлена.

Используем proxy-scraper как источник кандидатов, дополняем generic country list. Native helper проверяет доступность и страну через curl, а Chrome соединяется напрямую с проверенным upstream и повторяет контрольные запросы. Между extension и helper — только Native Messaging. Отдельного HTTP API или серверного relay нет.

Следствия: требуется однократная установка Python helper; интерфейс остаётся расширением Chrome. При отсутствии помощника сохраняется блокирующий маршрут. Поддержка любой выбранной страны использует один алгоритм и адаптивный таймаут, без исключения для NO. Изменение страны не требует изменения исходников. Системный VPN и публикация в Web Store не входят в эту версию.
