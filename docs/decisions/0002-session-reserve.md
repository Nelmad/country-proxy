# Резерв в памяти текущей сессии

Статус: принято для локальной 0.2.0. Дата: 2026-10-28.

После отказа повторный обход публичных списков занимает время и не гарантирует
наличия второго живого адреса. По запросу владельца помощник заранее проверяет
до двух резервов той же страны; разные протоколы/порты одного host и одинаковый
exitIp не считаются независимыми резервами.

Пул ограничен, имеет TTL 90 секунд и периодическое обслуживание. Он не хранится
на диске и не переносится между странами/запусками. При использовании адрес
повторно проходит native HTTPS-проверку и штатный browser probe. До успешного
browser probe действует блокировка прямого соединения. Отсутствие резерва
сохраняет существующий полный поиск.

Native-проверка фона не меняет активный маршрут Chrome. Проверка каждого резерва
через браузер в фоне потребовала бы временно переключать весь профиль, мешая
обычным вкладкам. Поэтому счётчик явно сообщает о проверке помощником; статус
«Подключено» относится только к подтверждённому Chrome активному адресу.

Пул сокращает повторный поиск при доступном резерве, но не обещает мгновенного
переключения или двух бесплатных IP для каждой страны. Проверки ограничены по
времени/числу задач и отменяются при stop/смене страны. Ошибка источника резерва
не отключает здоровое основное соединение.
