# ADR 0012. Вклад источников бесплатных прокси

Принято 1 ноября 2026 года для локальной разработки.

Одна строка списка может оказаться дублем, адресом из другого списка или
нерабочим прокси. Поэтому единица полезного результата — проверенный адрес
с точным протоколом, IP и портом. За фиксированное окно 300 секунд он даёт
один балл. Зеркала одного поставщика делят одну долю. Если источник сообщил
тот же адрес для нескольких стран, его доля делится между этими странами.
Правила подсчёта и пример дробного вклада приведены в [описании источников](../sources.md).

Для чтения результатов достаточно таблицы по стране в popup. История посещений,
сетевые ответы и сырые списки в отчёт не входят. При выборе другого набора
начинается новый учёт. Уход владельца с адреса и повторный health не увеличивают
число найденных рабочих прокси.

Выделять больше проверок источнику, который раньше чаще давал рабочие адреса,
выгодно, пока качество выдачи стабильно. В независимых сценариях смены качества
и редкой страны такой порядок терял рабочие адреса. Сохранены равные возможности
стран, обычная ротация поставщиков и очередь новых адресов. Экспоненциальное
увеличение паузы после ошибок поставщика также пропустило короткий период
доступности уникального прокси. Для повторного запроса сохраняется минута
или обязательный больший интервал поставщика. [Измерения](../verification.md).
