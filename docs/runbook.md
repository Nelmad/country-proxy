# Эксплуатация

**Нужен локальный помощник:** запустите Install.command в постоянной папке проекта. Он создаёт `.venv`, `.runtime/host` и одну регистрацию `local.country_proxy.json` в NativeMessagingHosts пользовательского Chrome. Не меняет системный прокси, не создаёт launchd, не загружает расширение сам. Если папка перемещена, удалите прежнюю регистрацию по старому пути явно и повторите установку.

**Нет адресов:** поиск повторяется автоматически. Списки кэшируются на 1–30 минут в зависимости от источника; проверки адресов выполняются заново. Подробности — [sources.md](sources.md). Можно добавить другую страну в настройках или подождать обновления публичных списков. Увеличенный таймаут уже применяется автоматически ко всем странам. Сообщение об источнике означает ошибку загрузки, а не доказанное отсутствие прокси во всей стране.

**Работает проверка, но не конкретный сайт:** сервис может блокировать публичные IP. Нажмите «Найти другой». Геопроверка не является проверкой требований конкретного сайта.

**Прокси управляется другим расширением:** отключите конфликтующее расширение или используйте отдельный Chrome-профиль. Country Proxy не обходит enterprise policy.

**Интернет заблокирован:** откройте popup и нажмите «Отключить». Если popup не работает, отключите Country Proxy в chrome://extensions: Chrome освободит его настройки. При удалении/отключении расширения его privacy overrides также снимаются. Настройки системы не изменяются.

## Удаление

1. Нажмите «Отключить», затем удалите расширение через chrome://extensions.
2. Удалите только `local.country_proxy.json` из `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/` (macOS) или `~/.config/google-chrome/NativeMessagingHosts/` (Linux).
3. По желанию удалите папку проекта вместе с `.venv` и `.runtime`. Это также удалит локальные тестовые отчёты. В других приложениях ничего не меняется.

Никаких аккаунтов, ключей и серверов проекта нет. Списки загружаются напрямую локальным помощником; проверки раскрывают прокси ваш сетевой IP и обращения к двум контрольным HTTPS-хостам. Проверяйте назначение публичного прокси перед использованием важных аккаунтов.

## Обновление исходников и откат

После локального обновления перезагрузите Country Proxy кнопкой Reload в chrome://extensions. Одного перезапуска Chrome или нового номера manifest недостаточно: тестом подтверждено выполнение старого service worker при новом номере версии. Это перезапустит helper с новыми адаптерами; выбранная страна сохранится. Для отката восстановите предыдущую версию исходников целиком и снова перезагрузите расширение. Не удаляйте пользовательские настройки и другие расширения.

## Изолированная проверка замены

`tests/failover.mjs` использует новый временный профиль Chrome for Testing при каждом запуске. Профиль, launcher и Native Messaging registration создаются внутри игнорируемой `.runtime/` и удаляются после завершения. Основной Chrome не используется. Любой тест сверяет фактически исполняемые background/controller scripts с файлами на диске. Для сценария сохранённого профиля используйте TEST_SAVED_PROFILE=1 TEST_RESTART=1 TEST_FAILURE=route TEST_RESERVE=1 с tests/failover-lab.mjs; он обновляет только тестовое расширение, если fingerprint устарел, и восстанавливает его регистрацию/настройки.

Отчёт `.runtime/failover-latest.json` содержит исходный и новый выходной IP, страну, события ошибок и смены маршрута. PASS требует обычной HTTPS-вкладки до и после замены, разных IP и неизменной страны. PARTIAL_NO_ALTERNATE означает, что автоматический поиск начался, но второго подтверждённого адреса не появилось за контрольный интервал. INCONCLUSIVE требует чтения поля error и диагностики; это не успешная замена.


**Резерв пуст:** это не отказ основного подключения. Пул наполняется в фоне,
если есть другие проверенные выходные IP выбранной страны. Просроченный или
отклонённый резерв удаляется. При перезапуске пул не восстанавливается с диска.
«Проверяем резерв» означает повторную проверку подготовленного кандидата; после
неё Chrome должен подтвердить HTTPS и страну. Если проверка не прошла, поиск
продолжается с блокировкой прямого маршрута.

При откате 0.2.0 остановите расширение, восстановите предыдущий комплект файлов
и выполните Reload. Список стран сохраняется, резерв создаётся заново. GitHub и
основной браузер обновляются только отдельным действием владельца.
