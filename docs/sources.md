# Источники бесплатных прокси

Базовые контракты проверены 2026-10-27; HProxy live API — 2026-10-29.
Все источники получают выбранный ISO-код страны;
NO/EE/AT не имеют отдельной логики. Списки служат только кандидатами. Работоспособность,
валидный TLS и фактическую страну выхода helper и Chrome проверяют независимо.

| Источник | Формат | Кэш успешного ответа |
| --- | --- | --- |
| [proxy-scraper](https://github.com/maximilianfeix/proxy-scraper) | закреплённая библиотека, country filter | 1 минута на страну |
| [hproxy live](https://hproxy.com/docs/free-proxy-list) | JSON array, country_code, protocols, status | 1 минута |
| [hproxy GitHub](https://github.com/hproxy-com/free-proxy-list) | country TXT, дополнительный список и резерв при недоступном API | 5 минут |
| [Proxifly](https://github.com/proxifly/free-proxy-list) | country TXT с протоколом | 5 минут |
| [ProxyScrape](https://docs.proxyscrape.com/api-reference/public-api/get-proxy-list) | API TXT с протоколом, timeout filter 60 секунд | 1 минута |
| [GeoNode](https://geonode.com/free-proxy-list) | JSON data, country, protocols | 5 минут |
| [Litport](https://github.com/litportnet/free-proxy-list) | live branch, country TXT | 5 минут |
| [ProxMint](https://proxmint.com/free-proxies#api) | JSON rows, countryCode, protocol | 30 минут |
| [Databay](https://github.com/databay-labs/free-proxy-list) | четыре country TXT, по протоколам | 5 минут |

ProxMint публикует данные по [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
В приложении данные фильтруются, нормализуются, объединяются и проверяются заново.
Litport просит обращаться к спискам не чаще одного раза в пять минут.

`native/sources.py` содержит адаптеры. Никакие аккаунты или ключи не нужны.
Для TXT country-файлов отсутствие файла (404) означает пустой список; остальные
ошибки возвращаются предупреждением, не отменяя удачные источники. JSON-адаптеры
дополнительно сверяют поле страны и отбрасывают неизвестные форматы.

HProxy live запрашивает до 200 строк для выбранной страны, без `recent=true`.
Принимаются только строки `status: alive`; `recently_alive` означает прошлую
проверку провайдером и не принимается. Записи с `tls_intercepted: true` или
некорректным значением флага отбрасываются; `false` и неизвестное (`null`/нет поля)
допускаются только к обычной строгой локальной проверке. Времена `last_alive_at`
и `last_verified_at`, а также статус провайдера не заменяют проверку helper/Chrome.
API возвращает массив верхнего уровня; обёртка с `data` не является его контрактом.
По документации порядок по умолчанию — сначала живые, затем быстрые. Ограниченная
выборка может не содержать всех доступных адресов; обещания наличия пары для страны
нет. Недоступный или изменивший формат API не отменяет GitHub и другие источники.

Одна страна может пользоваться всеми свободными загрузками. При конкуренции
ожидающие страны получают слоты по очереди: шесть для HTTP-списков и ещё один
для процесса proxy-scraper. Один и тот же запрос страны к источнику разделяется
между потребителями. Результаты хранятся в памяти помощника, не более 160 записей.
Даже после вытеснения списка помощник помнит ближайшее время повторного запроса:
обычная ошибка — минута, для Litport — не менее пяти минут. Кэш не подтверждает
работоспособность адреса.

Один ответ HTTP ограничен 2 000 000 байтами до разбора и отдаёт не более 120
адресов. Библиотечный процесс принимает только четыре HTTPS-ресурса двух зеркал
закреплённой версии. Проверка сертификата обязательна, редиректы и сжатые тела
не принимаются. Если глобальный каталог слишком велик или временно недоступен,
остальные списки продолжают работать. Процесс имеет собственный таймаут 28 секунд.

При общем лимите 120 уникальных комбинаций протокол/IP/порт одна большая выдача
не получает долю ещё работающих стран и провайдеров. Четыре файла Databay образуют
одну группу; оба источника HProxy — другую. Выход проверяется независимо от страны,
указанной поставщиком. API с ограниченной первой страницей не являются полным
мировым каталогом.

HTTP CONNECT и HTTPS transport различаются. `https://` в типизированных TXT
и файл Databay `https.txt` означают TLS до самого прокси. В GeoNode/ProxMint
метка HTTPS интерпретируется как HTTP CONNECT. Это же правило действует для
HProxy JSON: [описание проверки HProxy](https://hproxy.com/blog/err-tunnel-connection-failed)
разделяет обычный HTTP relay и HTTPS CONNECT tunnel. Самоподписанные сертификаты
прокси не принимаются: `--insecure` и `--proxy-insecure` не используются.
[README Databay](https://github.com/databay-labs/free-proxy-list/blob/master/README.md),
сверенный 16 ноября 2026, прямо допускает самоподписанные сертификаты proxy-hop
в `https.txt`. Такая запись всё равно должна пройти наш строгий TLS-контроль;
смена на HTTP или отключение проверки сертификата после TLS-отказа не применяются.
SOCKS4/SOCKS5 сохраняются как отдельные протоколы. Для адресов без указанного
протокола проверяются HTTP CONNECT, SOCKS4 и SOCKS5.

## Как читать вклад источника

Откройте «Вклад источников» и выберите страну списка. «Помощник» показывает
долю уникальных комбинаций протокола, IP и порта, прошедших проверку HTTPS и
страны выхода для выбранного набора. «Chrome» показывает долю адресов,
подтверждённых браузером. У резерва может быть балл только в первом столбце.
Строки отсортированы по вкладу. Тире означает, что завершённых проверок ещё нет.
«Обновить» читает свежую статистику текущей сессии.

Если адрес опубликовали A и B, каждый получает ½. Два зеркала A по-прежнему
получают ½ на двоих. Если A опубликовал адрес в списках NO и EE, в каждой
из этих строк отобразится ¼. Новое дублирующее наблюдение перераспределяет уже
начисленный балл. Страна списка описывает происхождение кандидата. Фактическую
страну выхода определяют свежие HTTPS-проверки. Уникальные адреса в двух
отчётах по странам могут пересекаться.

Пять минут отсчитываются от первой завершённой проверки адреса с результатом.
Повторный health и повторное подтверждение Chrome сохраняют исходную границу
окна. В сессии помещается до 5000 записей, включая адреса в ожидании проверки.
При переполнении записи с ближайшим сроком истечения выбывают вместе со своим
вкладом. Это может затронуть адрес, который ещё проверяется. Popup предупреждает,
если в текущей сессии отбрасывались наблюдения из-за лимита.
При новом подключении начинается новый отчёт.

Число запросов к спискам и подтверждённых ошибок относится к работе текущего
помощника. Чтение из кэша и объединение одновременных запросов учитываются
отдельно. Помощник хранит длительность запроса и локальное время получения.
У текущих форматов нет подтверждённого времени публикации всего списка,
поэтому возраст публикации остаётся неизвестным. Пустой список допустим.
